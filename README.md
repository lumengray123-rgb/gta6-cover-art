Neon Palms Cover Studio: a static offline web app that turns your photos and a caption into multi-panel GTA-style cover art — 4 panel layouts, 5 Vice City colour grades, per-panel crop and positioning, bold caption lettering, and PNG export in 1080×1080, 1080×1350 and 1920×1080. Fully offline, no network requests, all original art.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in desktop Chrome
```
